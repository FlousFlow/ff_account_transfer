# Flous Flow Internal Account Transfers

Paired internal transfers between bank and cash journals for **Odoo 18**.

See the module documentation in
[`ff_account_transfer/README.md`](ff_account_transfer/README.md).

## Installation

Add this repository to your Odoo addons path and install the
`ff_account_transfer` module.
